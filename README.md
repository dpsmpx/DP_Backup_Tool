Принцип действия программы: 
Программа предназначена для создания резервной копии структуры папок и метаданных файлов (размер, относительный путь), а также для восстановления файлов из неупорядоченной директории в исходную структуру. Она использует JSON для сохранения структуры и логирует ошибки/конфликты в файл backup_tool.log. 
 
-— 
 
Ключевые функции: 
1. Экспорт структуры: 
 - Сохраняет иерархию папок и информацию о файлах (имя, размер, относительный путь) в JSON. 
 - Игнорирует недоступные файлы (ошибки записываются в лог). 
 
2. Восстановление структуры: 
 - Создает папки и копирует файлы из исходной директории в целевую, используя размер файлов для сопоставления. 
 - Пропускает конфликтующие файлы (если они уже существуют в целевой папке). 
 - Если несколько файлов имеют одинаковый размер, программа выбирает первый неиспользованный (с предупреждениями в логе). 
 
-— 
 
Как использовать: 
1. Запуск программы: 
 - Выполните скрипт backup_tool.py. 
 - Появится диалоговое окно с выбором действия: 
 - Введите 1 для экспорта структуры. 
 - Введите 2 для восстановления. 
 
2. Экспорт структуры: 
 - Выберите корневую папку для сканирования. 
 - Укажите путь для сохранения JSON-файла. 
 - Результат: файл JSON с метаданными структуры. 
 
3. Восстановление структуры: 
 - Укажите JSON-файл с сохраненной структурой. 
 - Выберите исходную папку с файлами (неупорядоченными). 
 - Выберите целевую папку для восстановления. 
 - Программа создаст папки и скопирует файлы, основываясь на размерах из JSON. 
 
-— 
 
Особенности: 
- Логирование: Все ошибки и конфликты сохраняются в backup_tool.log. 
- Обработка дубликатов: При восстановлении, если есть несколько файлов одного размера, программа выберет первый подходящий, но предупредит в логе. 
- Безопасность: Существующие файлы в целевой папке не перезаписываются. 
- Тесты: В коде есть функция run_tests() для проверки работы (создает тестовые данные и проверяет экспорт/восстановление). 
 
-— 
 
Пример сценариев использования: 
- Резервное копирование структуры: Сохраните структуру важной папки перед переустановкой системы. 
- Восстановление после сбоя: Если файлы были перемешаны, программа вернет их в исходные папки, используя размеры для идентификации. 
 
Ограничения: 
- Восстановление по размеру может дать сбой, если файлы с одинаковым размером имеют разное содержимое. 
- Символические ссылки и права доступа не учитываются.
